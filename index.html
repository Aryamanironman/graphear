The principle

Every insight, three ways in.

One dataset, encoded three times. A student can switch channels without losing the finding — and a teacher can hand out the same data to a mixed classroom.

01 — SOUND

Hear the shape

Pitch maps to value, rhythm to sample order, stereo to series. Headphones optional; the encoding is consistent across datasets.

02 — TEXT

Read the finding

A plain-language description names the trend, the range, and the outlier — generated from the data, not written in advance.

03 — TOUCH

Print the curve

Export a tactile SVG sized for swell paper. Raised line, marked outlier, labelled axes — a graph a student can feel.

How it works

Drop a sheet. Press play.

01

Drop a CSV

Any column of numbers. No formatting, no template, no account. Parsing and sonification run locally in the browser.

02

Press play

Sixty-four samples become eight seconds of sound. Scrub with the arrow keys; space plays and pauses.

03

Take it with you

Export the plain-language description and a tactile SVG for swell paper. Both come from the same data as the audio.

What this is, honestly: a working browser prototype built during STEMergent Hacks 2026. CSV parsing, sonification, the description and the tactile export all run locally. It has not yet been tested with a classroom of blind students — that is the next step, and the reason the project exists.
